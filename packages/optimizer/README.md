# @stra/optimizer

**LS2 Cache & Optimize** | 编译优化器 — Static Signal Extraction + Action Inlining + Dead Signal Elimination

## 功能

- Static Signal Extraction: 静态 Signal 提取
- Action Inlining: Action 内联优化
- Dead Signal Elimination: 无用 Signal 消除
- Tree Flattening: 树扁平化优化

## 安装

```bash
pnpm add @stra/optimizer
```
