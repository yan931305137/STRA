# @stra/shared

**L0 Foundation** | Umbrella package — re-exports all `@stra/shared-*` packages.

## Install

```bash
pnpm add @stra/shared
```

## Exports

- Re-exports from `@stra/shared-core`
- Re-exports from `@stra/shared-node` (Node.js only)
- Re-exports from `@stra/shared-web` (Browser only)

Use this package when you need utilities across all platforms. For platform-specific builds, import from the sub-package directly.

See [PUBLIC_API.md](./PUBLIC_API.md) for the full API reference.
