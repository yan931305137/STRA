# @stra/semantic

**LS1 Semantic Layer** | 语义层 — Semantic Parser + Semantic Graph + Semantic ID + Semantic Hash

## 功能

- Semantic Parser: 语义解析器
- Semantic Graph: 语义图构建
- Semantic ID: 语义标识符
- Semantic Hash: 语义哈希
- Action Boundary: Action 边界检测
- Signal Dependency Tracker: Signal 依赖追踪

## 安装

```bash
pnpm add @stra/semantic
```
