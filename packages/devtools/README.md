# @stra/devtools

**L4 Tooling** | UI 调试工具 — tree / signal / action inspector

## 功能

- RuntimeDevtools: 运行时调试核心
- SemanticQueryEngine: 语义查询引擎
- DevToolsBridge: WebSocket 调试桥接
- Snapshot streaming: 快照流
- Immutable snapshot diff

## 铁律 / 约束

> ❌ 不包含 runtime 逻辑 | ❌ 不包含 AI

## 安装

```bash
pnpm add @stra/devtools
```

## 使用

```typescript
import { /* ... */ } from '@stra/devtools';
```
