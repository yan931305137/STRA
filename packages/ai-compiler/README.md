# @stra/ai-compiler

**LS3 Dev & AI** | AI 编译辅助 — AI-aware Compiler + Semantic Codegen + Runtime Guardrail

## 功能

- AI-aware Compiler: AI 感知编译器
- Semantic Codegen: 语义代码生成
- Runtime Guardrail: 运行时安全护栏
- Intent→Action Compiler: 意图到 Action 编译
- Refactor Engine: 重构引擎

## 铁律

> AI 不能直接修改 runtime — 必须通过 Runtime Guardrail 校验后通过 action 间接修改

## 安装

```bash
pnpm add @stra/ai-compiler
```
